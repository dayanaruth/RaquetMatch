# Contexto del proyecto: RaquetMatch
Autores: Dayana Ruth y Kevin | Sistemas Informáticos (Módulo 2)

## Objetivo
Web app para campeonatos de ráquet: registrar jugadores con nivel (1-5), armar equipos equilibrados, generar fixture todos contra todos y calcular la tabla de posiciones.

## Reglas de contexto usadas en Antigravity
- Stack: HTML5 semántico + CSS3 (Grid/Flex, variables, @media) + JavaScript vanilla. Sin frameworks.
- Estructura: /css /js /assets /docs, solo rutas relativas.
- Entrega extra: index en un solo archivo para abrir en cualquier navegador.
- Algoritmos: reparto "serpiente" por nivel; fixture por rotación circular (round-robin); 3 pts por victoria, desempate por diferencia de sets.
- Requisitos: 0 errores de consola, accesible (aria, labels), responsivo.
